# Task 2A · Retrospective census diagnostic

Run one retrospective CPU diagnostic on the selected initial detector (`yolo12m_seed0`). Use all ten Experiment 1 endpoints, all 2,000 archived draws per endpoint and the existing splits, block assignments, class maps, thresholds, matching rules, floors and alert targets. Keep each draw's threshold fixed throughout. Use the Task 2 fixed 200-image audit (`full_95`, whole blocks with possible overshoot) as the sampled audit. This choice ties the experiment directly to the reported Kent interval result. Verified Task 2 implementation · Verified coverage table

## Recall and decisions

1. At the archived operating threshold calculate recall for the sampled audit, the full calibration pool, and the full held-out set. For every pool use total matched reference boxes divided by total eligible reference boxes. Preserve zero-reference cases as unscorable. Retain sample size, block count, reference count and audit validity. The full calibration pool includes the sampled blocks.
2. Record the signed sampling difference (audit minus full calibration) and the signed difference between the two sets (full calibration minus held-out). Check that they sum to audit minus held-out on every estimable draw. Report the median signed and median absolute size of each difference by endpoint. An equality for signed differences does not imply additivity of absolute errors.
3. **Primary outcome:** cross-tabulate full-calibration recall versus held-out recall at the registered floor (four classes 0.30, potholes 0.25, equality clears). Give all four cell counts, both disagreement directions and the denominator of draws with both recalls estimable. This answers whether complete calibration labels put the detector on the same side of the floor on these two sets. A finite-pool census is a diagnostic reference, not a new uncertainty-based acceptance policy.
4. To answer whether more labels would help, also cross-tabulate the sampled point estimate versus the census versus held-out floor status on the same scorable draws. Count cases where moving from sample to census corrects a disagreement, introduces one, or leaves agreement or disagreement unchanged. Report the original three-way `full_95` action separately, retaining unresolved draws and audit shortfalls.
5. At the valid fixed 200-image look, count whether the same 95% audit interval contains both recalls, only full calibration, only held-out, or neither. Reconcile the held-out marginal with the verified Task 2 `full_n` and `full_inclusion` for every endpoint. Kent potholes should reproduce 1,470/2,000 (73.5%). These are descriptive inclusion counts on fixed splits. The audit's inclusion in the census matters for interpretation.

## Alert workload

At the same threshold count actual alerts per 100 images on the original **threshold-selection sample**, the full calibration pool, and the held-out set. The threshold-selection sample and the labeled recall audit have different roles. Use all images in each denominator, including zero-alert images. Preserve the confidence-tie convention. For target K, save the signed differences sample minus K, calibration minus sample, and held-out minus calibration. Verify that their sum equals held-out minus K. Per endpoint, report how often the full calibration and held-out rates each fall within the existing ±10% target band, including both disagreement directions. Reconcile held-out rates against Experiment 1.
